[Title 1]:
Problem Statement

[TextBox 2]:
2

[TextBox 3]:
Medical literacy gap: lab reports use dense terms, units and reference ranges that patients cannot interpret.
Indian report formats: values such as “2.33 Lakhs/cumm” or “1,50,000” break generic tools.
Prescription shorthand: handwritten names and codes like 1-0-1, BD, TDS cause dosing confusion.
Language barrier: reports are in English; many patients read Hindi, Marathi or Gujarati.
Unsafe AI answers: generic chatbots can guess values or imply a diagnosis.

============================== SLIDE 11 ==============================
[Title 1]:
Module 2: Machine Learning Risk Estimation

[TextBox 2]:
11

[Picture 3 PICTURE]: pos=(0.85, 1.90), size=(2.50, 4.95)

[TextBox 4]:
Stratified 80/20 split (seed 42); held-out set never used for selection
10 candidates per disease, 5-fold stratified CV on training data
Champion chosen by recall, then ROC-AUC, specificity, Brier score
Missing features return INSUFFICIENT_FEATURES, never a guess
Bands: LOW < 0.30 ≤ MODERATE < 0.70 ≤ ELEVATED

[Table 5 TABLE 4x3]:
  Condition | Selected model | Dataset
  Diabetes | Random Forest (depth 4) | Pima, 768 rows
  Heart disease | Logistic Regression (C = 1.0) | UCI Cleveland, 297
  Kidney disease | Logistic Regression (C = 10) | UCI CKD, 400 rows

Module 3: Prescription Explainer

[TextBox 2]:
12

[Picture 3 PICTURE]: pos=(1.08, 1.90), size=(1.94, 4.95)

[TextBox 4]:
Photo / PDF: Gemini reads the image into structured JSON; Tesseract OCR is the fallback
Text parsing: regex extracts dose (500 mg), frequency (1-0-1, OD, BD, TDS, SOS), timing and duration
Drug catalogue: 29 common medicines, 103 generic and brand aliases (e.g. Glycomet, Dolo)
Safety: unknown or illegible items get needs_confirmation and a pharmacist prompt

  0-0-1 | Night only (bedtime)
  TDS / SOS | Three times daily / only when required

[Title 1]:
Database Design and REST API

[TextBox 2]:
16

[Picture 3 PICTURE]: pos=(0.54, 1.90), size=(3.93, 4.95)

[Table 4 TABLE 8x2]:
  Endpoint | Purpose
  /api/v1/auth/* | Register, login, Google
  /api/v1/extract | Document text extraction
  /api/v1/reference/analyze | Classify verified values
  /api/v1/ml/predict/* | 3 risk models
  /api/v1/genai/explain | Plain-language summary
  /api/v1/prescriptions/* | Explain and store Rx
  /api/v1/history | Unified user timeline

[TextBox 5]:
7 tables with cascading foreign keys. History is stored per user, so one account can never read another’s records. Passwords: PBKDF2-SHA256, 100,000 iterations.
